Tasks is a straightforward list of things to do. Your own to-dos live here alongside follow-ups that Relaya recommends or creates for you.

## Filtering

Switch between two views:

- **My tasks** — tasks assigned to you
- **All open** — every open task in the workspace

## Adding a task

Add a task at any time, with an optional **due date**. When something has a deadline, set it — that timing helps the right work rise to the top of [Today](/docs/using/today).

## Getting things done

Mark a task **Done** when you finish it. **Overdue** tasks are highlighted so they don't slip.

## Where tasks come from

Every task carries a tag showing its origin:

- **You** — tasks you created
- **Recommended** — suggestions from Relaya
- **Agent** — created by the follow-up agent as it works on your behalf

:::note
Recommended and agent tasks are suggestions and reminders — they're to-dos, not actions taken. Anything an agent wants to actually _send_ goes through [Approvals](/docs/using/approvals) first.
:::

## Linking to a record

A task can link to a related **account** or **deal**, so the context travels with it and you can jump straight to what it's about.

## Where to go next

- See your most urgent tasks surfaced in [Today](/docs/using/today)
- Review agent-drafted actions in [Approvals](/docs/using/approvals)
- Follow a linked task through to its [deal](/docs/using/pipeline)
